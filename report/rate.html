Rate control: quantize → predict → entropy code

Each window is one block group spanning a minute (60 blocks): 5 consecutive seconds of each of the 12 signal kinds, with every block rescaled to [0, 1] to simulate a single sensor moving through different operating regimes. Results are averaged over 5 groups (one per report seed). Bits per sample are measured over full block groups with all framing overhead included, while errors are computed per block as absolute values (equivalent to a percentage of each block's full scale) and summarized across all blocks or by signal kind.

Regenerate: cd experimental && uv run python make_rate_report.py.

Method

  • Per-block pipeline. Each block is uniformly quantized via q = round(x / Δb)—the only lossy step, guaranteeing |err| ≤ Δb/2—then differenced with order ∈ {0, 1, 2, 3} chosen per block and passed to an entropy coder. Everything except the Rice and FLAC bit-packing is vectorized NumPy.
  • Window rate control. A single shared step Δ is bisected across the entire block group so the group averages 4 bits/sample including headers. Any block that would exceed 8 bits/sample on its own receives a coarser step Δ·2e/8 (stored as a 1-byte exponent e per block). Under uniform quantization, a shared step is the MSE-optimal way to allocate a fixed total bit budget.
  • Fixed rate control. For comparison, every block is independently driven to 4 bits/sample in isolation using the same format, and the final block group takes whatever total size results.
  • Framing. The Rice coder concatenates length-prefixed block payloads. Both zstd and deflate make a single compressor call per block group over flags, starting values, and byte planes. FLAC writes one stream per block group with one frame per block. best: … stores a 1-byte coder ID per block followed by each coder's sub-group of the blocks it won.
  • Coders. delta0123-rice uses FLAC-style partitioned Rice coding (2p partitions, each with its own parameter k, choosing order, p, and k by exact bit cost). delta0123-zstd (level 9) and delta0123-deflate zigzag residuals into the narrowest byte width, apply byte-stream-split, and compress. flac runs libFLAC level 8 (LPC up to order 12) on the same integers, counting frame bytes only. best: … picks the smallest standalone coder per block plus a 1-byte coder ID. 0-order entropy computes the zero-order entropy of the best residual plus headers; it is a reference rather than a real codec or lower bound, since partitioned Rice, LPC, and LZ matching adapt locally within a block and can beat it.
  • One-shot codecs (delta0123-zstd-B). Rather than searching for Δ, these set the step directly to block range / (2B − 1), pick the difference order minimizing var(diff(q, k)), and make one zstd level-3 call per block group, lowering B only if a block's estimated size would exceed 8 bits/sample. delta12-zstd-8 restricts the order choice to 1 and 2 for speed.
  • Every real coder is round-trip verified on every block group.
