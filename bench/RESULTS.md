# fluxcode gigabyte benchmark (bench/bench_gb.py, 2026-11-21, AC power; decode is per block group, as rows are read)

A complete run of the value-exp encoder after escaped samples, the noise estimate's early exit on clean blocks
and Params.tolerance (default 0, so not exercised here). Against the run before (same day, before those): sizes
unchanged; default encode 6.01 → 5.71 µs/block (−5%: clean blocks skip the 12th differences, escapes cost
0.1–0.2 µs), decode 1.69 → 1.75 µs/block (+0.06 µs, within run-to-run spread). Against main (d0c80b1, 2026-11-01):
all 15 signals 4.76 → 4.01 bits/sample (−16%, almost all of it the random walks, now floored), encode
5.12 → 5.71 µs/block (+12%), decode 1.79 → 1.75 (−2%). Python path only (FLUXCODE_RUST=0).
On the realistic corpus of experimental/value/ the same encoder is 28% smaller on high-rate DAQ-like signals
and 13% on 1 s historian tags (docs/TUNING.md).

Apple M3, Darwin 25.6.0, Python 3.11.13, numpy 2.4.6

15 signal types x 149 minutes = 1.00 GiB of float64 (134,100 blocks); best of 3.
